# Employee Attrition Predictor with Segments

### Overview

An end-to-end Machine Learning project that predicts employee attrition and identifies employee segments using classification and clustering techniques.

### Objectives

- Predict whether an employee will stay or leave.
- Identify factors associated with employee attrition.
- Segment employees based on their characteristics.
- Compare different ML algorithms and evaluate their performance.

### Dataset

HR Employee Attrition dataset containing employee details such as age, department, job role, monthly income, job satisfaction, work-life balance, overtime and years at company.

**Dataset Size:** 1,470 records and 35 columns.

**Target Variable:** `Attrition` (Yes/No)

### Technologies Used

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Imbalanced-learn

### Machine Learning Algorithms

**Classification:**

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM
- Naive Bayes

**Clustering:**

- K-Means
- Hierarchical Clustering

### Project Workflow

1. Data Loading and Understanding
2. Exploratory Data Analysis
3. Data Preprocessing
4. Feature Encoding and Scaling
5. Classification Model Building
6. Handling Imbalanced Data
7. Model Evaluation and Hyperparameter Tuning
8. Employee Segmentation
9. Cluster Analysis

### Evaluation Metrics

- Accuracy, Precision, Recall and F1-score
- Confusion Matrix and ROC-AUC
- Elbow Method and Silhouette Score
  
### Key Findings

- The dataset contains 1,470 employee records.
- Approximately 83.88% of employees stayed, while 16.12% left the organization.
- The target variable is imbalanced.
- No missing values or duplicate records were found.
- Employee overtime, job satisfaction, department, age and years at company are among the features explored for their relationship with attrition.
