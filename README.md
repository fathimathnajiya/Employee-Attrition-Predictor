# Employee Attrition Predictor with Segments

Predicts how likely an employee is to leave (Logistic Regression) and groups employees into 4 segments (KMeans). Built with Streamlit on the IBM HR Analytics dataset.

## Run
pip install -r requirements.txt
streamlit run app.py

## Files
- app.py: the Streamlit app
- hr.csv: dataset
- Employee_Attrition_Predictor.ipynb: full analysis
